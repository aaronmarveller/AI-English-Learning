# 09 — Practice 语音输入

**What to build:** 学习者能真的开口说英语，并且看得见自己被识别成了什么；麦克风不可用时自动有退路。

回显识别文本是**必须项**，不是锦上添花：初学者发音不准时识别经常出错，若不回显，学习者只会反复收到「再试一次」却无法归因，会当场卡死。

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] 主输入方式为麦克风，点击后开始收音并有可见的收音状态
- [ ] 学习者说的话以文本形式回显在下方气泡，识别错误时能一眼看出是识别问题
- [ ] 可切换到文字输入，两种输入方式走完全相同的对话逻辑
- [ ] 浏览器不支持语音识别或麦克风权限被拒时，自动切换到文字输入并说明原因
- [ ] 语音识别被封装在适配层后，页面不直接依赖具体浏览器接口；适配层对外暴露能力探测
- [ ] E2E（stub 语音识别）覆盖：识别结果回显、能力不可用时自动降级并给出说明
