# 08 — Practice 对话骨架（文字输入驱动）

**What to build:** 学习者用文字输入就能与 Emily 完成一次完整的四步对话练习——说对了推进、说不对停留在原地再试，四步走完解锁学习总结。

本票刻意**先不做语音**，让对话核心自己就能完整演示，也让自动化验收不依赖麦克风。语音在 09 号票接上。

Conversation State Machine 的转移契约（来自 AI Configuration，是本功能的核心约定）：

```
Conversation Start → Greeting → Check-in → Response → Closing → Complete → Review

每轮学习者输入后由 Validation Result 决定：
  accepted     → 推进到下一状态
  needs_retry  → 停留在当前状态，鼓励再试
  off_topic    → 停留在当前状态，接住后引导回主题
```

服务端每轮返回的四项：判定结果、Emily 的英文回复、对应中文翻译、本轮表现标记（表现标记持续累积，供 Review 选择反馈模板）。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 进入页面后 Emily 主动发出开场白，学习者无需先开口
- [ ] Emily 每句回复不超过 20 个英文单词，一次只提一个问题，使用 A1–A2 难度的词汇
- [ ] 对话严格按 Greeting → Check-in → Response → Closing 顺序推进，不可跳步，同一时刻只有一个状态激活
- [ ] 每轮学习者输入由服务端统一返回判定结果、英文回复、中文翻译与表现标记四项
- [ ] 判定为通过时推进到下一状态；判定为需重试或跑题时停留在当前状态
- [ ] 判定以沟通意图为准：意思正确即算通过，轻微语法或拼写错误不影响结果
- [ ] 答得不对时 Emily 鼓励再试并引导回当前这一步；跑题时先接住再温和带回，均不使用负面评价
- [ ] Emily 立绘呈现待机、说话、思考三种状态：待机为缓慢呼吸，说话时有动效，思考时有等待指示
- [ ] 当前轮以双气泡呈现：Emily 消息在上、学习者输入回显在下；进入下一轮时替换
- [ ] 四步对话进度实时更新并高亮当前步
- [ ] 四步全部完成前，查看学习总结按钮保持禁用
- [ ] 完成后 Emily 给出一句简短鼓励并邀请查看总结，按钮解锁
- [ ] 对话始终围绕本节主题，不进入开放式自由聊天
- [ ] API 密钥只存在于服务端；构建产物中搜索密钥前缀零命中
- [ ] E2E（stub 模型响应）覆盖：通过推进、需重试停留、跑题停留、四步完成解锁按钮
