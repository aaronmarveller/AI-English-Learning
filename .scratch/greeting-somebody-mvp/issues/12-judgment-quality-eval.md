# 12 — 判定质量 eval

**What to build:** 一个能在演示前回答「模型判得准不准」的评测工具。

这是本项目的**第二个测试接缝**，存在的唯一理由：主接缝（浏览器 E2E）里模型是被 stub 的，所以它答不了本 MVP 最大的技术风险——模型究竟会不会把白名单之外的自然表达判为通过。这是模型行为问题，不是代码问题，只能打真实接口验证。

它同时充当提示词的回归保护：改了 system prompt 就重跑一次。

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] 一条命令可对真实模型接口运行一张「学习者话术 × 期望判定」表
- [ ] 话术表覆盖四个对话状态各自的：白名单内表达、白名单外但意图正确的自然表达、意图错误的表达、跑题表达
- [ ] 至少包含一条明确的白名单外自然表达用例（如 "Yeah, doing alright" 在 Check-in 阶段应判为通过）
- [ ] 输出逐条结果与总体通过率，失败项能看出期望与实际的差异
- [ ] 该评测不纳入常规测试流程，需手动执行（非确定性且产生费用）
- [ ] 记录一次基线运行结果，供后续修改提示词时对照
