# 11 — Review 页

**What to build:** 学习者在练习结束后收到一段**看得懂的中文**复盘，反映自己这次的真实表现，并能选择重练或继续。

反馈用中文是刻意决定：A1 学习者看不懂英文反馈，复盘环节的目标是让人真的接收到信息。英文模板句作为引用嵌在中文里（例如「下次试试看：I'm doing pretty good.」）。

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] 反馈按固定顺序呈现：鼓励 → 学习亮点 → 一条改进建议 → 结束语
- [ ] 数量固定为：鼓励 1 条、亮点 2–3 条、建议 1 条、结束语 1 条
- [ ] 亮点依据 Practice 累积的表现标记选择，反映本次真实表现而非固定文案
- [ ] 多条模板都适用时随机选取，避免每次反馈完全一样
- [ ] 反馈以中文叙述，其中的英文例句保留英文原文
- [ ] 建议以「下次试试」的正向措辞给出，不强调错误、不使用负面评价
- [ ] 反馈逐条显示，条与条之间有适当间隔，并有输入中指示，模拟自然聊天过程
- [ ] 反馈全部显示完成前，重练与继续下一课两个按钮保持禁用
- [ ] 点击重练回到 Practice，且对话与表现标记已重置为干净状态
- [ ] 点击继续下一课进入 Coming Soon 占位页
- [ ] 不出现分数、等级或数据统计
- [ ] E2E 覆盖：逐条显示期间按钮禁用、播完解锁、重练后对话为空、亮点随表现标记变化
