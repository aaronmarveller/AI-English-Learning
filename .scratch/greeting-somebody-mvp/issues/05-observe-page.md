# 05 — Observe 页

**What to build:** 学习者在学任何表达之前，先看一段真实场景视频建立情境，并知道该留意什么。这一步没有任务，只是观察。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 页面标题与场景名展示本节场景（邻里之间偶遇打招呼）
- [ ] 视频进入页面时显示封面，不自动播放、不自动出声
- [ ] 点击播放后开始播放，支持暂停、重播、进度、音量、全屏等标准播放控制
- [ ] 视频可开启英文字幕
- [ ] Watch for 区块展示本节要留意的四个交流环节（打招呼、问候、回应、结束对话）及其中文
- [ ] Watch for 各项仅作展示，不可点击或展开
- [ ] 未播放完视频也能进入 Explore
- [ ] E2E 覆盖：默认不自动播放、无需看完即可继续
