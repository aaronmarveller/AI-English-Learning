# 01 — 项目初始化与设计系统

**What to build:** 一个能跑起来的手机端应用外壳，以及从 UI 设计稿抽取的完整设计令牌。附一个样式基准页，把令牌全部可视化，供与设计稿逐项比对。

这个项目的头号要求是「视觉严格照抄设计稿」。令牌抽错了后面六个页面全要返工，所以先把它单独验收一次。

**Blocked by:** 无 — 可立即开始

**Status:** ready-for-agent

- [ ] 开发服务器可启动，生产构建可通过
- [ ] 设计令牌以主题变量形式定义：主色深蓝、强调绿、绿色浅底、页面背景米白、卡片白、卡片圆角、按钮圆角
- [ ] 英文使用几何无衬线字体、中文使用思源黑体系，中英混排时基线与字重协调
- [ ] 存在手机壳容器：移动端全宽，桌面端定宽居中；任何视口下页面主体都不出现横向滚动
- [ ] 存在样式基准页，展示全部色板、字阶、圆角，以及主按钮的常态/按下/禁用三态
- [ ] 样式基准页在 390×844 视口下与 UI 设计稿的配色和字号一致
