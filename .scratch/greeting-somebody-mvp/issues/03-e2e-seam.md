# 03 — E2E 接缝

**What to build:** 一套浏览器端到端测试载体，覆盖导航脊柱的行为，并成为后续每一张票挂验收用例的地方。

这是一张 prefactor 票，本身不新增任何用户可见行为。它必须排在 02 之后（没有可跑的应用就无从测起），又必须排在所有页面票之前（否则每张票各造一套测试脚手架）。

采用的是本项目的**主接缝**：真实浏览器驱动，只 stub 两处真正的外部边界——大模型代理路由与 Web Speech API，其余全部走真实代码。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 一条命令可运行全部 E2E，默认在手机视口下执行
- [ ] 测试只断言用户可观察的行为，不断言内部状态字段或函数调用次数
- [ ] 覆盖：六步顺序走通，进度点逐步递进
- [ ] 覆盖：未完成前序步骤直连后续地址被重定向回 Home
- [ ] 覆盖：带调试参数可直达任意步骤
- [ ] 覆盖：任意步骤刷新后进度不丢
- [ ] 提供 stub 大模型响应与 Web Speech API 的通用夹具，供后续票复用
- [ ] 测试全绿，且在干净检出后一条命令可复现
