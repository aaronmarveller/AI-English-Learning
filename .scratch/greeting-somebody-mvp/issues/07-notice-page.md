# 07 — Notice 页

**What to build:** 学习者理解中美打招呼在「对谁说」「说完还聊不聊」「聊什么」三方面的差异，知道为什么不用认真回答 "How are you?"。目标是理解真实交流方式，不是记忆语言形式。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 三张 Cultural Insight Card：会和谁这样打招呼、打完招呼会继续聊吗、通常会聊什么
- [ ] 每张卡展开后呈现美国与中国两侧的对比；手机视口下上下堆叠，不用左右分栏
- [ ] 每张卡包含一段「为什么」的解释
- [ ] 默认展开第一张卡
- [ ] 展开任一张卡时其余自动收起，同一时刻只有一张展开
- [ ] 未展开所有卡也能进入 Practice
- [ ] 不含互动测验、收藏或标记功能
- [ ] E2E 覆盖：默认展开第一张、手风琴单开语义、无需展开即可继续
